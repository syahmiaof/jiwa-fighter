## Not exercised or blocked

- No `AI_GATEWAY_API_KEY` or `SATRIA_MODEL` was configured. The live provider call, provider timeout and model response guardrails could not be exercised. The provider adapter is present, but configured LLM mode remains unverified.
- The in-memory, per-process throttle is prototype abuse protection. It is not shared across serverless instances and should not be treated as production rate limiting. The request identity depends on proxy headers, so deployment must use a trusted proxy or edge-level limiter.
- `npm audit --omit=dev` reported **two production dependency vulnerabilities**: one critical finding affecting the installed Next.js 14 line and one high PostCSS finding. The audit offered `npm audit fix --force`, which would move to Next.js 16.4.3 and is a major upgrade. No forced major upgrade was applied.
- Screenshot comparison against references covers all nine routes at 1536 × 1024. Secondary viewport checks are layout smoke checks, not route-by-route reference image comparisons.
- This checkout has no tracked Git baseline; `git status` reports project files as untracked. Before/after review relies on saved screenshots, not a trustworthy commit diff.
